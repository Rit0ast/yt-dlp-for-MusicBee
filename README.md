## Getting Started

### Prerequisites
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) installed and available on `PATH`
- [ffmpeg](https://www.ffmpeg.org/) installed and available on `PATH`

Check if yt-dlp and ffmpeg are set up correctly:
```bash
yt-dlp --version
ffmpeg -version
```

#### Notes
- After setting up `yt-dlp` and `ffmpeg`, restart MusicBee
- Built using MusicBee Plugin API v3.1
- Built using .NET 4.8
